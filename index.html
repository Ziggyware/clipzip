Windows clipboard utility

clipzip / clipunzip

Turn a fenced file bundle on the clipboard into a zip, and write that zip back out as files. Same idea as clipin and clipout, pointed at archives.

clipzip.exe  → zip
clipunzip.exe → unzip

clipzip

default --zip

Reads path + fenced content from the clipboard and replaces it with a zip. Relative paths stay inside the archive.

c:\test> clipzip
c:\test> clipzip bundle.zip

clipunzip

default --unzip

No arguments previews paths, byte sizes, packed sizes, totals, and unsafe entries. Pass a destination or --unzip to extract.

c:\test> clipunzip            # preview
c:\test> clipunzip --unzip    # extract here
c:\test> clipunzip .\out     # extract there

Preview layout (illustrative):

BYTES        PACKED  PATH
          12            14  file_path/file_name.ext
          13            15  file_path/file_name2.ext

2 file(s), 0 folder(s), 0 unsafe/unreadable

Round trip

Clipboard before clipzip. After it, clipunzip previews the zip; use --unzip to write files.

    Flags
    
    
    
      
        
    
          Flag
          Effect
        
    
          
      
        
    --zipForce zip, even if the exe is clipunzip
    
        
    --unzipExtract into current folder unless a destination is provided
    
        
    --listShow metadata without writing files
    
        
    --b64Zip mode: clipboard gets Base64 text
    
        
    --traceDiagnostics on stderr
    
        
    --helpHelp. No clipboard change.
